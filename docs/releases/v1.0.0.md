# GatewayOps v1.0.0 发布说明

- **版本**：`v1.0.0`
- **对应提交**：`a02f956454196554b41df76bff9277db83e7835d`（短 ID：`a02f956`）
- **提交日期**：2026 年 10 月 12 日（UTC+8）

GatewayOps v1.0.0 面向 NewAPI / Sub2API 运营场景，提供渠道监控、中转站管理、成本分析、通知和 OAuth 号池管理。作为首个正式版本，本说明汇总截至上述提交已具备的主要能力。

## 主要功能

### 渠道管理与鉴权

- 集中管理 NewAPI 和 Sub2API 渠道，支持多账号、登录测试、启用与停用、余额刷新、倍率刷新和自动同步。
- 支持账号密码与 Token 凭据、自定义登录 Headers 和参数；NewAPI 支持 Cookie + User ID 及长期访问令牌，Sub2API 支持 Access Token + Refresh Token 自动刷新。
- 支持自动读取和手工维护余额、分组及倍率，提供低余额阈值、余额历史、倍率变化记录和监控日志。
- 支持渠道账号关联 Sub2API 中转站账号，并通过模型目录搜索渠道和账号。

### Sub2API 中转站运营

- 同步账号、分组、渠道、用户及关联关系，分别配置快照同步和倍率探测计划。
- 管理账号分组、并发、优先级、调度状态与池模式重试次数，支持连接测试、分组快速测试及批量配置。
- 根据上游成本倍率与销售倍率识别风险，提供调组建议，并支持自动调组、无盈利账号处理和自动优先级调整。
- 保存手动与自动调整的审计记录，支持通过渠道关联、手工倍率或自动关联补充账号成本信息。

### 运营总览与公开监控

- 提供今天、24 小时、7 天和 30 天视图，汇总渠道余额、倍率变化、账号风险、成本采集、自动调整及收支数据。
- 持久化渠道与中转站用量记录，展示近期调用、消费趋势、响应延迟和时间稳定性统计。
- 提供多中转站公开监控入口 `/public/relay-monitor`，支持站点选择；单站页面使用 `/public/relay-monitor/:stationID`。
- 公开分组监控支持时间范围筛选、浏览器缓存和每 30 秒自动刷新。
- 提供官方服务状态页面 `/public/service-status`，汇总 OpenAI 与 Claude 的服务状态和事件历史。

### 公开模型价格

- 提供 `/public/model-pricing/:stationID`，展示销售分组实际可用的模型及有效价格。
- 区分系统默认定价、渠道覆盖定价和分组独立生图定价，支持 Token、按次及不同分辨率的生图价格展示。
- 支持模型与平台等关键词搜索、平台和计费模式筛选，以及浏览器缓存和手动刷新。

### 成本账本与本地号池

- 维护收入、账号采购、上游充值、退款及其他运营收支，账本记录可关联渠道、中转站或本地账号。
- 按时间范围和中转站汇总数据，提供现金净额、采购成本、充值支出、当前渠道余额、实际消耗成本及实时倍率等对账指标。
- 同步 OAuth 账号及使用统计，查看账号状态、用户扣费、请求次数和 Token 数。
- 支持订阅方案筛选、到期时间展示与排序，以及本地账号采购成本、预计额度、有效期和备注维护。

### 通知与安全配置

- 支持 Telegram、Webhook、SMTP 邮件、企业微信、钉钉、飞书和 Bark 通知，覆盖余额不足、倍率变化、登录失败及监控失败等事件。
- 支持渠道与分组过滤、消息合并、变化幅度过滤、低余额冷却和发送失败重试。
- 支持 Turnstile 验证码服务，适配 CapSolver、2Captcha、Anti-Captcha 和 YesCaptcha。
- 提供后台登录、敏感配置加密及系统设置持久化；iframe 嵌入默认关闭，可配置域名白名单和 Glob 匹配规则。

## 修复与体验优化

- 完善 NewAPI User ID 鉴权，以及 Sub2API Refresh Token、过期时间校验和已有凭据的编辑体验。
- 修复配置加载期间的默认值闪现，增加加载占位、页面错误边界和路由恢复，改善页面白屏问题。
- 复用中转站快照、预取数据和共享请求，取消过期请求并优化搜索更新调度。
- 统一管理列表的标题、筛选及操作区，完善账号批量操作菜单和调度筛选。
- 完善批量新增账号、最近调用展示及短时倍率探测任务配置。

## 部署与使用要点

- **部署方式**：支持 Docker Compose，前端资源嵌入 Go 二进制，由单个应用容器提供页面与 API；Compose 配套 PostgreSQL 16，镜像工作流支持 `linux/amd64` 与 `linux/arm64` 构建。
- **必填配置**：设置 `GATEWAYOPS_DATABASE_PASSWORD` 和 `APP_SECRET`。公网部署需开启 `AUTH_ENABLED=true` 并设置 `ADMIN_PASSWORD`；后台登录默认关闭。
- **Compose 配套配置**：该提交的模板引用 `.outbound-proxy.env` 和外部网络 `sub2api-deploy_sub2api-network`。部署前需准备该文件（不使用代理时可为空）及网络，或按实际环境调整模板。
- **分组 API 密钥**：添加中转站并完成同步后，需在 Sub2API 的 `/keys` 为销售分组创建并启用分组 API 密钥，再执行同步。模型价格与分组快速测试依赖这些密钥；缺失时可能出现价格不完整或 `group_admin_api_key_missing`（HTTP 422）。
- **数据备份**：升级已有部署前，同时备份 PostgreSQL 数据与 `APP_SECRET`。更换或丢失 `APP_SECRET` 会导致已有敏感配置无法解密。

## 已知说明

- 中转站管理当前适配 Sub2API 管理 API；NewAPI 支持渠道管理与监控。
- 公开监控状态来自近期调用记录，用于观察趋势，不保证实时可用性。
- 账本现金净额表示已记录的收支差额，不直接等同于利润。
- 此提交的 `/api/version` 仍返回 `0.1.0-dev`，本次发布版本以 `v1.0.0` 及上述提交 ID 为准。
