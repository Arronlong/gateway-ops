# 鹈鹕测智多来源实施方案

## 行为约定

- 渠道保留现有记录和手动入口，独立页明确显示自动测智关闭、部分开启或全部开启。
- 本地号池沿用已有账号级配置、调度和作品，不复制任务；独立页仅把开启的 OAuth 账号作为单独组列出。
- 中转站分组使用独立配置与历史，默认关闭；通过该销售分组的调用 Key 执行全局方案，不能随意选组内账号来冒充分组测试。
- 分组管理提供开关、测一次和最近三份结果；独立页把开启的中转站分组作为一行。
- 分组监控复用同一批分组作品，只读展示，不允许修改、触发或删除；公开接口同时验证分组公开和监控状态。
- 所有来源沿用全局任务总开关、测试方案、北京时间执行窗口、频率和保留数量；列表继续用静态缩略图，详情才运行动画。

## 实施顺序

1. 失败测试覆盖状态标注、号池入库筛选、分组隔离、租约、保留策略和公开接口授权。
2. 增加分组配置和作品表、迁移、图库、执行与调度，接入设置变更。
3. 复用作品组件，增加分组和只读作用域，接入号池、分组管理、分组监控和独立作品页。
4. 完整后端测试、前端测试、类型检查、构建和模拟浏览器验证；不触发真实付费生成，也不替用户开启自动任务。

## 工作区

直接修改主分支，保留现有未提交代码，不创建 worktree，不自动提交。
