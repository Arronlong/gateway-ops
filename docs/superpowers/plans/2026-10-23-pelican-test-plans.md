# 鹈鹕测智独立方案

## 目标与数据约定

以 `pelican_plans` 数组替换单套模型、题目、思考强度和并行份数配置。每项为 `{model, prompt, reasoning_effort}`，模型字段保留有序回退列表语义。默认一项，可添加或删除，至少一项、最多八项，沿用现有单轮并发上限。

当前配置迁移为第一项，旧并行份数不扩展为多项。统一的北京时间执行时段、频率、渠道账号开关保持原有职责。每次手动或定时触发快照全部方案，并行各执行一次；单项失败独立保存，不影响其他项。结果保存实际模型、原始题目和强度。

## 实现步骤

1. 扩展配置存储、校验和读写接口，支持新数组及旧配置兼容读取，覆盖迁移、空数组、数量上限和逐项校验。
2. 修改执行链路，按方案并行预检与生成，共用账号锁和批次生命周期；覆盖不同模型、不同强度、单项失败和真实并行测试。
3. 设置页改为方案列表，支持新增、删除、单独模型优先级、题目恢复默认和中英强度选择；移除并行份数输入。测一次的可用状态改为读取方案数组。
4. 验证手动、定时、默认值和迁移路径，执行前后端检查，在浏览器验证保存回读、增删与窄屏布局。
5. 重启服务，确认真实旧配置可正常读取，保留用户配置且不触发额外付费生成。

## 分工

主执行者负责后端存储、执行、接口验证及服务重启；前端实现任务限定前端文件，按以上接口约定并行完成。最终审查检查方案隔离、数量与配置快照，以及历史结果和账号开关不受影响。
