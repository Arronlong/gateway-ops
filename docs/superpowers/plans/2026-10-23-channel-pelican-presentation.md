# 渠道测智呈现调整

## 已确认要求

- 保持原账号测智的开关、手动测试、全局配置和凭据读取逻辑。
- 渠道画册卡片底部直接展示最近 3 份结果，并提供一键重试及查看更多。
- 独立页面按渠道分组，每个渠道占一整行，信息在上，最多 30 份结果横向排列。
- 最近结果按完成时间和记录 ID 倒序，同一渠道的重复关联去重；不同站点的相同账号 ID 隔离。
- 多个渠道关联同一上游账号时继续共享任务及历史，不迁移、不删除原数据。

## 实施顺序

1. 先补充渠道聚合、去重、数量上限和页面结构的失败测试。
2. 增加只返回安全元数据的渠道测智查询，复用当前账号关联和作品详情接口。
3. 复用原测智控件和动画预览实现卡片内嵌展示，列表入口跳转对应渠道结果。
4. 将独立页面改为按渠道整行展示，保留搜索、筛选、删除及动画交互。
5. 运行后端测试、前端类型检查、回归测试、构建和桌面／手机浏览器验证，重启主分支服务。
