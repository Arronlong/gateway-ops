# 产品名称与统一图标设计

- 日期：2026-10-26。
- 状态：用户已选择原型方案 A；已实现并完成验证。
- 目标：在系统设置中配置产品名称和产品图标，顶部品牌栏、浏览器标签、所有路由页面标题统一使用该配置；未配置时使用首页现有默认品牌。

## 1. 已确认的范围

1. 采用方案 A：所有页面的产品标识和页面主标题使用统一产品图标。
2. 默认产品名称为 `GatewayOps`；默认图标复用首页的黑底白色 Activity 图标，不重新设计一套图案。
3. 首页、渠道管理、中转站管理、鹈鹕测智、成本管理、本地号池、系统设置、验证码服务、预警中心、登录页和公开页面均纳入检查范围。
4. 页面标题的文字保留原有业务含义，不把所有标题改成产品名称。
5. 导航菜单、功能分区、统计卡片、操作按钮、服务商及上游站点的业务图标不替换为产品图标。
6. 版权主体、许可证、项目来源及第三方标识不随产品名称配置改写。

## 2. 设置界面与交互

- 在系统设置顶部的版本卡片之后增加“品牌与产品名称”卡片，沿用现有边框、字体、间距和按钮样式，不改变其他配置块的顺序或行为。
- 左侧放产品名称输入框、当前图标、上传图标和恢复首页默认图标；右侧预览顶部品牌栏、页面主标题和浏览器标签。
- 窄屏下改为上下排列，不产生水平溢出。
- 编辑只更新卡片内草稿与预览；点击保存成功后才更新实际应用品牌，避免把未保存内容传播到其他页面。
- 使用现有系统设置保存流程，保留其他系统配置；保存中禁止重复提交，失败保留草稿并展示明确错误。
- 恢复默认图标仅清除图标草稿，不修改产品名称；保存后生效。

## 3. 配置定义与兼容

| 字段 | 含义 | 默认及校验 |
| --- | --- | --- |
| `product_name` | 可自定义的产品展示名称 | 默认 `GatewayOps`；剔除首尾空格；空值恢复默认；最多 40 个 Unicode 字符 |
| `product_icon` | 自定义产品图标的 PNG 数据地址 | 默认空字符串，表示使用首页默认 Activity 图标；仅接受经过校验的 PNG 图像数据 |

- 在现有 `app_settings` 中增加两个独立配置键，不新增数据库表、文件存储服务或额外环境变量。
- 扩展已有系统设置前后端类型、默认值、读取、存储和接口校验。
- 旧数据库缺少配置键、旧接口响应缺少字段时使用默认品牌，不出现空白图标或空白名称。
- 修改其他系统设置时保留已保存的品牌字段；恢复默认图标保存为空字符串，不删除其他配置。

## 4. 图标上传与安全边界

- 上传入口支持 PNG、JPEG、WebP，原文件不超过 1 MiB。
- 浏览器解码成功后按原比例缩放并居中到 128 × 128 的 PNG 画布，保留透明区域，不拉伸、不裁切主体；保存的是转换后的 PNG，不是文件路径或临时对象地址。
- 不接受远程图片链接、SVG 或 HTML，避免引入服务端远程抓取和主动内容处理。
- 服务端独立检查数据地址类型、Base64、PNG 文件签名、实际图像解码结果、尺寸和大小；拒绝伪造类型及损坏图片，不能仅相信扩展名。
- PNG 尺寸上限为 128 × 128，解码后的文件大小上限为 512 KiB；接口限制请求体大小，避免超大输入。
- 自定义图片加载失败时回退到默认 Activity 图标；图标必须有固定尺寸并保留原始比例。

## 5. 统一展示架构

- 提供单一品牌状态及统一 `ProductIcon` 组件；页面不再自行拼接或复制产品图标。
- 在现有路由外层挂载品牌提供器，使登录页、需鉴权页面和公开页面都能读取同一套品牌。
- 新增只读公开接口 `GET /api/public/branding`，仅返回 `product_name` 和 `product_icon`，不得通过该接口暴露完整系统设置。
- 品牌公开读取失败时显示默认品牌，不影响鉴权和业务页面加载。
- 系统设置保存成功后刷新品牌状态；新打开或刷新的页面通过公开品牌接口获取最新配置。
- 浏览器标签标题统一为“页面名称 · 产品名称”；已有中转站名称等上下文保留在页面名称部分，避免动态标题被覆盖。
- 浏览器页签图标和 Apple touch 图标均从同一品牌来源生成；首屏静态资源也提供默认 Activity 图标，移除当前指向不存在图标资源的引用。
- 顶部品牌栏、登录页品牌、公开页已有品牌区域和路由页面主标题改用统一组件；不借机重构导航布局或添加新的大型品牌横幅。
- 原有页面中若确有 Sato API 或空白产品标识，统一接入同一品牌来源；不将外部渠道自身的 Sato API 名称误当成本产品品牌替换。
