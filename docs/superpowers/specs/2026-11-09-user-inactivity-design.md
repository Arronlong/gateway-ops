# 用户长期未使用

在预警中心新增 `user_inactive` 场景，默认 30 天，可配置 1–3650 天。直接复用现有通用处理选项、通知、恢复、审计和动态范围机制。

- 以上游最后使用时间计算连续未使用天数；可确认从未使用时从创建时间计算。
- 仅使用有效且新鲜的用户快照；时间缺失、未来时间或上游不支持时返回数据不足。
- Sub2API 支持最后使用时间；当前 NewAPI 用户接口不提供该字段，不将登录时间替代使用时间。
- 阈值复用 `condition.threshold`，单位为天，不依赖用量日志窗口或最小请求数。
- 前端新增场景和天数输入，隐藏无关的统计窗口，摘要和通知显示正确的单位。
