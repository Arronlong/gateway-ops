# 四项等权综合评分

## 已确认的规则
- 成功率、稳定性、缓存命中、延迟各占 25%，各项为 0～100 分。
- 四项统一使用系统设置的 1～24 小时滚动窗口，截止当前时间前 45 秒，最多取最近 60 次。
- 成功率与缓存分直接复用环形指标的计算口径。缓存使用 Token 加权比例，不使用命中请求比例。

## 稳定性的独立定义
- 只评估相对延迟波动和连续失败，不重复计入平均成功率或绝对延迟。
- 对成功请求的首字、总耗时分别计算波动分：`100 / (1 + 标准差 / 均值)`，再取可用维度的平均值。
- 连续失败系数：`1 - max(0, 最长连败 - 1) / (有效尝试数 - 1)`。
- 稳定性分 = 波动分 × 连续失败系数。没有请求的空档不视为故障。
- 至少需要两次有效尝试及两次同维度成功延迟；否则稳定性未知。至少两次尝试全部失败时稳定性明确为 0。

## 延迟与缺失值
- 延迟仅评估成功请求；失败请求快速返回不能获得性能奖励。
- 沿用既有阈值：首字 10 秒内满分、30 秒及以上 0 分；总耗时 60 秒内满分、180 秒及以上 0 分；中间线性扣分。
- 缺少任一项时不重新分配权重，综合分显示 `--`，悬浮说明列出缺项。
- 少于 10 次有效尝试时标注低置信度；综合分四舍五入为整数。
- 渠道与中转站的列表、画册、排序共用同一套评分。
